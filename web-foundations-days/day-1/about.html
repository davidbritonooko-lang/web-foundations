About Quick Notes

Quick Notes is a simple web application designed to help you capture your ideas and thoughts before they slip away. Whether you're brainstorming, jotting down reminders, or keeping track of important information, Quick Notes provides a straightforward interface to manage your notes efficiently.

This application was built as part of the Web Foundations course, where we learned the basics of HTML, CSS, and JavaScript. The goal was to create a functional and user-friendly note-taking app that can be easily extended with additional features in the future.

How to use QuickNotes

  • Create a new note. Click the input box stated Type here..
  • Type your content. Enter your title and details directly into the workspace; the app automatically saves your text in real time.
  • Organize and close. Assign a tag or folder to your note if needed, then close it to return to your main dashboard list.

Keyboard Shortcuts
